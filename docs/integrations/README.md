# Integrations

Short, copy-paste guides for common meta-frameworks:

- [Nuxt](./nuxt.md) — compiler option, `<ClientOnly>` floating player
- [SvelteKit](./sveltekit.md) — layout-level floating player, the `$audio` store
- [Astro](./astro.md) — plain elements, `transition:persist`
- [Plain HTML from a CDN](./vanilla-cdn.md) — one module script, no build step

The framework basics are in [frameworks.md](../frameworks.md).
